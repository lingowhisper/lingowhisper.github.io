# Lingo Whisper

Sitio web estático bilingüe (Español / English) para servicios de traducción y corrección.

## Archivos
- `index.html` — estructura y contenido.
- `style.css` — diseño responsive.
- `script.js` — selector de idioma y menú móvil.
- `logo.svg` — logotipo editable en formato vectorial.
